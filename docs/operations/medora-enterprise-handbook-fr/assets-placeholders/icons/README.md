# Placeholders — Icônes

**Dossier:** `assets-placeholders/icons/`  
**Phase:** M-BOOK.FR.11

---

## Usage

Icônes optionnelles pour export PDF/DOCX (puces, rôles, alertes). **Non requis** pour MVP export.

---

## Convention de nommage

```
medora-fr-icon-{usage}.svg
```

**Exemples:**

- `medora-fr-icon-role-rn.svg`
- `medora-fr-icon-alert-phi.svg`
- `medora-fr-icon-mobile.svg`

---

## Règles

| Règle | Exigence |
|-------|----------|
| **Licence** | SVG internes Medora ou libre droits |
| **Taille** | 24×24 ou 32×32 px base |
| **Couleur** | Compatible N/B pour impression |
| **Langue** | Pas de texte dans l'icône — légende externe FR |
