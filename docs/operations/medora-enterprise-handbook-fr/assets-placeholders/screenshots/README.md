**Dossier:** `assets-placeholders/screenshots/`  
**Phase:** M-BOOK.FR.11

---

## Usage

Stocker les captures d'écran du manuel enterprise **après** campagne de capture dédiée. Ce dossier est vide en phase FR.11 (scaffolding uniquement).

---

## Convention de nommage

```
medora-fr-v{volume}-{workflow}-{viewport}.png
```

| Segment | Exemples |
|---------|----------|
| volume | `v1`, `v2`, … `v9`, `vx` |
| workflow | `triage`, `trackboard`, `roi`, `pharmacie-file` |
| viewport | `desktop`, `tablette`, `mobile` |

**Exemple:** `medora-fr-v2-triage-tablette.png`

---

## Règles de capture

| Règle | Exigence |
|-------|----------|
| **Patient fictif** | Dossier formation / test uniquement — **obligatoire** |
| **PHI** | Interdit — revue double avant commit repo |
| **Langue** | Interface locale **française** |
| **Viewports** | Desktop 1440×900 · Tablette 768×1024 · Mobile 390×844 |
| **Format** | PNG, sRGB, pas de métadonnées GPS |
