# Placeholders — Diagrammes

**Dossier:** `assets-placeholders/diagrams/`  
**Phase:** M-BOOK.FR.11

---

## Usage

Stocker les diagrammes source (SVG) et exports PNG pour le manuel enterprise.

---

## Convention de nommage

```
medora-fr-diag-{domaine}-{variante}.svg
medora-fr-diag-{domaine}-{variante}.png
```

**Exemples:**

- `medora-fr-diag-triage-flux-principal.svg`
- `medora-fr-diag-roi-cycle-vie.png`

---

## Règles de création

| Règle | Exigence |
|-------|----------|
| **Langue** | Libellés 100 % français |
| **PHI** | Aucune donnée patient |
| **Style** | Simple, lisible impression N/B |
| **Format source** | SVG préféré |
| **Export PDF** | PNG 300 dpi minimum |
