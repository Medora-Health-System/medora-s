# Phase 16 — Operational Manual

1. Seed Wave 1 candidates: `pnpm medication:phase16:seed`
2. Promote with provenance to shadow: `pnpm medication:phase16:promote-shadow`
3. Run shadow evaluation: `pnpm medication:phase16:shadow:evaluate`
4. Review admin dashboard: `/app/admin/medication-governance/recommendations`
5. Providers view read-only cards: `/app/provider/medication-recommendations`
6. Certify: `pnpm medication:phase16:certify`

Never enable Pilot/Active from CLI or admin UI in Phase 16.
