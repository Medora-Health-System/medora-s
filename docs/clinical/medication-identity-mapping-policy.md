# Medication Identity Mapping Policy

Canonical generic = normalized ingredient / combination identity.

Not separate concepts: indication, dose, strength, route, brand, package, facility, protocol, source dataset.

Outcomes include NEW_CANONICAL_CONCEPT, EXISTING_CANONICAL_MATCH, EXISTING_CONCEPT_NEW_PRODUCT, DUPLICATE_REJECTED, AMBIGUOUS_MATCH, CONFLICT_REQUIRES_REVIEW, SOURCE_INSUFFICIENT.

Ambiguous matches fail closed. Fuzzy match may suggest only.
