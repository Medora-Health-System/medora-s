# Orderability Report

A catalog row is **provider-orderable** when:

- active
- not test/nonclinical
- not linked to BLOCKED/RETIRED product
- has genericName, strength, dosageForm, route

Ordering path: provider search → select CatalogMedication → order create by catalog id. Dual-layer activation is not required.
