# Phase 16 — Governance Guide

Recommendations may only originate from approved authoritative knowledge / expert-authored drafts with provenance.

Every exposable recommendation must retain:

- source / evidence links
- evidence level
- recommendation strength
- approval status, reviewer, timestamp
- version
- confidence score
- constitutional audit trail (`MedicationRecommendationAuditEvent`)

Admin workspace covers queue, evidence, confidence, review, activation status (blocked beyond shadow), shadow analytics, coverage, quality, approval, version history, and audit.
