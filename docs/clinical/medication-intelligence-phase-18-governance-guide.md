# Phase 18 — Governance Guide

Version states: CURRENT, SUPERSEDED, RETIRED, ARCHIVED, EXPERIMENTAL, SHADOW, PILOT.

Approved versions are sealed (`immutableAt`, `contentHash`). New evidence requires a new version — never overwrite.

Rollback restores a prior approved version while preserving audit, history, lineage, evidence, and reviews. Never deletes records.

Drift alerts are governance-admin only and must never interrupt providers.
