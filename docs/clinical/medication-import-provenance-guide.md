# Provenance Guide

Every Wave 3 CREATE carries:

- source key / version / checksum
- import job id / importer version
- CatalogMedication `dataSourceLabel=MEDORA_CURATED_WAVE3`
- Concept code `EM_W3C_*`
- Product `baselineSource=EM_KNOWLEDGE_EXPANSION_WAVE3_IMPORT_V1`
- `dualLayerLinkageMethod=WAVE3_IMPORT`

Precedence: reviewed Medora decisions > approved terminology > labeling > facility formulary > unreviewed candidates.
