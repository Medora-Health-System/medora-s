# Phase 18 — Monitoring Guide

Tracks recommendation generation/views/acknowledgements/dismissals, disagreements, confidence/coverage, knowledge freshness, review backlog/aging, stale evidence, pilot/facility/provider/version utilization, and latency buckets (recommendation/API/shadow/governance).

Safety: high disagreement/override, stale/expired evidence, conflicts, overdue review, pilot failures, suspension/rollback frequency, instability, confidence degradation, drift, duplicates/orphans.

Mutation counters must remain zero.
